# Owner checklist

Do these in order. The words to paste are in [curseforge.md](curseforge.md) and [wago.md](wago.md). Why the release already uploads, and the TOC lines to add later, are in [RESEARCH.md](RESEARCH.md). Never put a token in the repository, in a commit, or in a chat.

1. Create the CurseForge project at <https://authors.curseforge.com/#/projects/create/choose-game>. Choose World of Warcraft, then the class Addons. When it asks which version, choose Forever (the public list is <https://www.curseforge.com/wow/search?class=addons&gameVersionTypeId=88568>), not Retail and not Classic.
2. On General, set the name and summary from [curseforge.md](curseforge.md), and upload `logo/curseforge-avatar.png`. Main category Unit Frames (HUDs if that subcategory is offered as the main choice). Additional categories, four at most: Action Bars, Map & Minimap, Bags & Inventory, Quests & Leveling. The guide is <https://support.curseforge.com/en/support/solutions/articles/9000199552-project-submission-guide-and-tips>.
3. On Description, switch to Markdown and paste the description from [curseforge.md](curseforge.md).
4. On License, pick All Rights Reserved, or Custom with the sentence in [curseforge.md](curseforge.md). The licence list is loaded for the game. The policies are <https://support.curseforge.com/en/support/solutions/articles/9000197279-project-and-modpack-moderation-policies>.
5. Open the new project from <https://authors.curseforge.com/#/projects>. On Images (the empty screen says "Upload screenshots to your project"), upload `gallery/` in the numbered order with the titles and captions in [curseforge.md](curseforge.md). On the project's source and issues fields, set <https://github.com/korallis/KstyleUI> and <https://discord.gg/A5qqGZEXyN>.
6. Copy the numeric project id. The packager ignores a slug. It is the number in the authors console URL (`#/projects/<id>`) and the id the [upload API](https://support.curseforge.com/en/support/solutions/articles/9000197321-curseforge-upload-api) means by `{projectId}`.
7. Create the Wago project at <https://addons.wago.io/developers/projects/create> (it sends you through <https://addons.wago.io/auth/login> first). Name, summary and markdown description are in [wago.md](wago.md). Game version Forever, patch 1.60.1 (<https://addons.wago.io/api/data/game>). Categories: Unit Frames, Action Bars, Map & Minimap, Bags & Inventory, Quests & Leveling (<https://addons.wago.io/api/data/categories>). Licence: All Rights Reserved.
8. On the project, set source and website to <https://github.com/korallis/KstyleUI> and the support URL to <https://discord.gg/A5qqGZEXyN>. Upload `logo/wago-icon.png`. Upload the gallery at `https://addons.wago.io/developers/projects/<slug>/gallery/create`, in the numbered order, captions from [wago.md](wago.md).
9. On <https://addons.wago.io/developers>, copy the 8-character id printed under the project name. That is `X-Wago-ID` ([docs.wago.io](https://docs.wago.io/#adding-the-wago-project-id)).
10. Create a CurseForge API token at <https://authors.curseforge.com/#/settings/api-tokens>. The form asks for a name and no scopes. One token is the whole key.
11. Create a Wago API key at <https://addons.wago.io/account/apikeys>. The docs describe one bearer token and no scopes ([docs.wago.io](https://docs.wago.io/#authentication)).
12. Add both to the GitHub environment named `release`, not as repository secrets and not in a file. Open <https://github.com/korallis/KstyleUI/settings/environments>, open `release`, and add `CF_API_KEY` (the CurseForge token) and `WAGO_API_TOKEN` (the Wago key). `release.yml` already reads those two names from that environment.
13. Send the coordinator the numeric CurseForge project id and the 8-character Wago id. The TOC lines those become are the diff in [RESEARCH.md](RESEARCH.md). Do not send the tokens. A later change adds the two lines to `KstyleUI.toc`. Until those lines are on `main`, a tag packages and uploads to GitHub, and skips CurseForge and Wago, which is what the packager does when the ids are absent. The README already has `CF_URL` and `WAGO_URL` comments where the two store links belong. Filling those is a later README edit.

## Every feature release

Update [description.md](description.md), the master, so every section describes what the release ships, and keep the Discord invite right under the banner. Keep it short: a new headline feature gets one clip with one line under it. Add its shots to `CLIPS` in `Tools/media/marketing.py` (rendered over the real plates with `--strict`), run `python3 Tools/media/marketing.py --clips <name> --pages`, and paste the new blocks into CurseForge and Wago once the release puts the images on `main`.
