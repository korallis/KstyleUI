# Feature map

The G1/G3/G7/G10/G11 finish controls default on in their matching module pages. `RENDER_FINISH=previous` switches them off for parity captures, including loading native windows with the previous spacing choice after a reload. [Window finish options](statecharts/window-finish.md) charts the reload flow.

One row per player-facing feature, in the names the README and the v0.1.0 changelog use. Briefs, tickets and PRs use these names. A PR that adds, renames or removes a feature updates its row.

- **Where** is the settings window page (`/kstyle`) or the slash command where the player finds it. A module page carries the module's name; General holds the HUD style, Appearance and Widgets sections; Elements holds the Layout section.
- **Code** is the main code path, relative to the repository root.
- **Tests** are the regression files under `Tools/regression/` that cover it. `test-<name>*` means every file with that prefix.
- **Render** is the scene under `Tools/render/scenes/` and the `RENDER_*` variables that show it. Run it with the app driver in [AGENTS.md](../AGENTS.md#app-driver): `bash Tools/render/shoot.sh <scene> --strict`, with the variables in front.

Audit H feature controls are on the matching Options pages: Party and Raid (role/threat shapes, debuff letters, status icons and raid manager), Nameplates (threat shapes and interrupt shield), Unit Frames > Target (range fade), Meters (tank alarm), Action Bars (binding helpers and finished third bar), Elements (mover clarity and search), Profiles (scoped review and recovery backups), and General (setup Close/replacement, addon notices and settings controls). Existing Standard/Compact presets and the colour-vision Standard choice restore their previous appearance. `RENDER_NEEDS_OFF=1` selects these previous behaviours in the audit scenes for pixel-equality evidence.

The Medallions minimap has three **Minimap frame** choices: **Crest medallion** (default), **Crest ring**, and **Classic**. `minimap_plaque` covers its saved corner position; `hud_reference` covers its default beside the buff rows and story cards. Both accept `RENDER_MINIMAP_FRAME=medallion|ring|classic`, with `RENDER_HUD_STYLE=Medallions` for the HUD scene. The crest choices preserve the visible map area while reserving the larger ring footprint.
