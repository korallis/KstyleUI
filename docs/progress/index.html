Release and hotfixes

Latest published release

v0.3.5.3 · Follow the game's UI scale

Choose the game's UI scale in setup or General settings. Pixel-perfect sizing remains the default. Setup-placed windows keep their place as the scale changes; older damage meter placements need setup applied again.

v0.3.5.2

The HUD no longer shrinks below its normal size when a bar shape cannot fit. For two-row bars, default-position frames lift clear; manually placed frames stay put.

v0.3.5.1

The quest card folds from its header and remembers its state, alongside fixes for chat, trainers and settings.

A release for a completed class follows its crest and cooldown work; hotfixes can ship in between. The hunter class release is still waiting.

Recent fixes and open work

  • Released: v0.3.5.2 fixes HUD sizing and lifts default-position frames clear of two-row bars while leaving manually placed frames alone; v0.3.5.3 keeps setup-placed windows in position when the game's scale changes.

  • On staging: the older cooldown viewer fix follows HUD width changes again. The v0.3.5.4 hotfix is awaiting its release checks.
