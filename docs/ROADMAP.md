# KstyleUI roadmap

What's coming next, release by release. Dates are estimates; we'll keep this post up to date as each release ships. v0.3.5 is out now: the crest comes alive, with every class's tracking built into the crest itself and ten new crest effects. A new release lands each time a class's crest work is finished, with hotfixes in between.

## v0.3.6 — the crest, tuned in game

Estimated: within a few days.

The new crest checked on the live client and tuned from your feedback, class by class.

Highlights:

- Anything on the crest that doesn't look or behave right in game gets fixed, class by class.
- Your ideas for what each class should show on the crest, built in.
- A lighter crest: fewer textures with everything lit, for smoother frames in big fights.
