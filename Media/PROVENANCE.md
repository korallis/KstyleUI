# Media provenance

Every file in `Media/` has a row here: where it came from, how it was made, and when. No file is copied from another addon.

## Fonts

All fonts are under the SIL Open Font License 1.1; `Media/Fonts/OFL.txt` holds each project's licence text. The licence text sits beside the files. No font has a Reserved Font Name that the files below would break: Source Sans's "Source" applies only to modified versions, and its files are unmodified; Cinzel's licence names no Reserved Font Name, so renaming the modified Cinzel Tracked is a courtesy, not a duty.

Lumen's faces come from [google/fonts](https://github.com/google/fonts) at commit `5bb28733cec313b63fbd415b574b5ae35c8aa8b8`, downloaded on 2026-11-09. `Tools/media/make_fonts.py` makes the five files from the sources with fontTools (4.68.0 for the first four; 4.60.2 gives the same bytes for Cinzel SemiBold, which was checked, and made Cinzel Tracked), run from a throwaway virtual environment outside the repository (its docstring has the commands; `--only cinzel` needs just `Cinzel[wght].ttf`). It saves without touching the timestamp, so running it again gives the same bytes.

Why the digits are remapped: the game's text renderer applies no OpenType features, so a font always draws its default figures. Alegreya Sans's default figures are oldstyle and proportional (the 3, 4, 5, 7 and 9 drop below the baseline, and each digit has its own width). The mockup asks for `font-variant-numeric: tabular-nums lining-nums`, and the font has `tnum` and `lnum` features the game cannot turn on, so the files point the digits straight at the tabular lining glyphs. Numbers then keep their width as they change, and no widget needs a fixed-width reservation for them. Cinzel's figures stay proportional; Cinzel is used for headings and captions, which do not count.

Why Cinzel is widened: the game has no letter-spacing call. `FontString:SetSpacing` is line spacing (Blizzard_APIDocumentationGenerated/SimpleFontStringAPIDocumentation.lua; the UI source uses it only on wrapped text) and no method on a FontString or a Font, nor any attribute in `UI.xsd`, spaces letters. Spacing letters with thin spaces needs a thin-space glyph, which Cinzel lacks (the game draws a box). So the tracking is part of the face: every advance is 0.08 em wider, as the owner's picture sets its headings. A pixel fit of the picture's headings against Cinzel Regular at weight 400 (the glyphs drawn at the role's 20.6 to 20.75 px, tracking 0 to 0.15 em, subpixel offsets, summed squared difference of the ink) puts the three gold captions at 0.08 to 0.09 em (SKYBORNE), 0.08 (QUESTS) and 0.11 to 0.12 (DAMAGE), and 0.08 em jointly; measured on the render, SKYBORNE's ink is 118 px at 0.07 em against the picture's 119 and its first letters sit 109 px apart against 111. The picture's white headings fit less tracking: 0.02 to 0.03 (WINDFIELD ORCHARD), 0.05 (LIGHTNING BOLT) and 0.03 to 0.04 (SHADOWGALE POACHER). The picture's strokes are heavier than weight 400; the same fit at weight 500 gives 0.07 for the gold captions. The 0.15 em that a first reading of the picture suggests would make the word wider than the picture's. The captions carry no drop shadow in the picture (the pixels beside each stroke on its lower right are as bright as those on its upper left), so the face is drawn without the kit's text shadow. Build the file with fontTools alone: with `uharfbuzz` installed fontTools packs GPOS differently and the bytes of both Cinzel files change, though the glyphs and advances do not. The 0.15 em that a first reading of the picture suggests would make the word wider than the picture's. `Widgets.ApplyFont` takes back the space the last letter leaves behind. The font has no thin space either, so nothing can space it with one.

Lumen is the default font set: Cinzel SemiBold for display, heading and caption text, Cinzel Tracked (Regular, spaced) for the `caps` role, Alegreya Sans Tabular Regular for body text, Bold for numbers and Medium with an outline for text over the world. Source Sans 3 Semibold, Source Sans 3 and Inter stay selectable; picking one sets every role to that face, with Source Sans 3 Semibold (whose digits are tabular by default) for numbers.

## Procedural textures and logo

`Tools/media/make_media.py` draws these files. No image model or prompt is involved: each texture is a shape or a smooth function sampled 4x4 times per pixel and averaged. Run `python3 Tools/media/make_media.py` to redraw them and this table.

Shapes are white with their coverage in alpha, so the game tints them with `SetVertexColor`. Chamfers and bevels are drawn at 4 texels per root unit. A texture with slice margins is a nine-slice source: a corner piece of `m` texels draws at `m / 4` root units, so the corners of the fill and both bevel lines line up. Every row and column between the margins is the same, so the edges and centre stretch cleanly. The shadow is drawn at 2 texels per unit: its 48-texel corner pieces are 24 units, centred on the panel's corners. `python3 -m unittest discover -s Tools/tests` fails when a file differs from what the script draws.
