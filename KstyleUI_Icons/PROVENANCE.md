# KstyleUI_Icons provenance

Icon set A. Every icon in `Icons/` has a row below. `Tools/icons/iconset.py package` writes this file and the icons from the generation records; do not edit it by hand.

| Field | Value |
| --- | --- |
| Model | Higgsfield `gpt_image_2_5` |
| Settings | `--aspect_ratio 1:1 --resolution 1k --quality high` |
| Style reference | `docs/design/mockups/icons_A_luminous.jpg`, passed as `image_references` |
| Seed | The model exposes none; the Higgsfield job ID identifies each image |
| Post-processing | Pillow: Lanczos downscale from 1024 to 128 pixels, luminance only (RGB PNG with R = G = B) |
| Checks | `Tools/icons/check_icons.py --set A`: no blank, small, clipped, off-black, coloured or text-bearing image is accepted |

Each `style` prompt is the row's prompt text followed by this style block:

```text
Draw one simple, iconic subject that captures this ability: a single object, creature head, hand or symbol seen up close, centred and filling about two thirds of the square, with a wide margin of pure black on every side. Use bold, thick, solid shapes with a bright glowing core and a clean outline, and only a little smoke and a few sparks around it, so the silhouette reads clearly when the icon is shrunk to 32 pixels. No scene, no landscape, no full-body characters, no busy background. Style: match the reference image exactly: a sculpture of glowing white light and luminous white smoke on a pure black background, strictly monochrome greyscale, no colour at all. One icon only, not a grid or a sheet. No text, no letters, no numbers, no runes, no writing, no border, no frame, no rounded square, nothing touching the edges.
```
